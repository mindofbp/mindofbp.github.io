Laplace BIE Solver

The Laplace problem on a separated domain, normally written with the differential operator, can be rewritten as a boundary integral equation. This leads to several analytic and numerical niceties. In this project, given Dirichlet boundary data, I solve the resulting integral equation for the unknown density layer and evaluate inside the domain. Specialized quadrature is used to improve accuracy near and on the boundary which requires the integration of a nearly-singular or singular integral. Code to come...

Resound.fm

I was one of the founding engineers of Resound and designed the system architecture for initial scale. We built a ML-powered audio/video editor in the browser, lots of problems related to the efficient transport and playback of large files in the browser. I also worked on an inverse problem, turning AAF files into decision trees of user editing actions.
